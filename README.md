# ECPC Community — SGU

A responsive front-end landing page for the ECPC Community at New Salhia University (SGU).

## Files
- `index.html` — page structure and content
- `style.css` — responsive UI and visual design
- `script.js` — mobile menu, smart team fields, registration success state

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.
