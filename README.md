# ECPC Community — SGU

A responsive front-end landing page for the ECPC Community at New Salhia University (SGU).

## Files
- `index.html` — page structure and content
- `style.css` — responsive UI and visual design
- `script.js` — mobile menu, smart team fields, registration success state

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## Important
The registration form is currently front-end only. The JavaScript prevents the page refresh and displays a success state, but it does NOT store submissions.

Connect the form to your preferred backend, Formspree, Firebase, Google Apps Script, or your own API before using it for real registrations.

## Customization
1. Replace the demo gallery blocks with actual SGU/ECPC photos.
2. Replace the placeholder statistics with real community numbers.
3. Add your official SGU logo if you have permission to use it.
4. Update the university email domain if different.
5. Connect the registration form to a real database/service.
